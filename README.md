# Treeple

A social network for arborists and the homeowners who need them. Anyone can
join and ask questions; only accounts with a current ISA certification get the
**Arborist** Root Flare and can answer them.

- [`DESIGN.md`](DESIGN.md) — product and technical design: Root Flare and
  account types, verified-only answers, recognized ISA credentials, the
  verification flow and flair lifecycle, data model, stack, and roadmap.
- [`prototype/`](prototype/) — clickable, no-build prototype of the feed, Root
  Flare, verified-only answers, profile, and ISA verification flow. Open
  `prototype/index.html` in a browser. The ISA lookup is simulated; a cert
  number ending in `X` simulates a failed lookup.
