# Treeple

A social network for arborists and the homeowners who need them. Anyone can
join and ask questions; only accounts with a verified tree-care credential
(ISA certification, TRAQ, TCIA CTSP, state license, and more) get the
**Arborist** Root Flare and can answer them.

- [`DESIGN.md`](DESIGN.md) — product and technical design: Root Flare and
  account types, verified-only answers, advice-only labels, recognized
  credentials, company pages, the verification flow and flair lifecycle, data
  model, stack, and roadmap.
- [`prototype/`](prototype/) — clickable, no-build prototype of all of the
  above. Open `prototype/index.html` in a browser. Credential lookups are
  simulated; a number ending in `X` simulates a failed lookup.
