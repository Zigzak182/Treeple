# Treeple

A social network for arborists. Anyone in the trade can join; the **Verified**
badge is reserved for people with a current ISA certification.

- [`DESIGN.md`](DESIGN.md) — product and technical design: membership tiers,
  recognized ISA credentials, the verification flow and badge lifecycle, data
  model, stack, and roadmap.
- [`prototype/`](prototype/) — clickable, no-build prototype of the feed,
  profile, and ISA verification flow. Open `prototype/index.html` in a browser.
  The ISA lookup is simulated; a cert number ending in `X` simulates a failed
  lookup.
